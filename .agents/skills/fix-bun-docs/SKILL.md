# Fix Bun Docs

## Purpose

The official Bun documentation at `https://bun.com/docs` serves raw Markdown
files that carry two upstream artifacts which break a local mirror:

1. Every page starts with a three-line `Documentation Index` blockquote that
   is noise for local browsing.
2. Every internal link uses an absolute path such as
   `[loaders](/docs/bundler/loaders)` which points at the remote site root and
   does not resolve inside the local mirror.

This skill fixes both problems in one pass with a Bun script.

## When to use

Use this skill right after The Librarian acquires a new version of the Bun
documentation (`docs/bun - vX.Y.Z/`), and before the `index.md` entry point
is generated.

## What the script does

The script scans every `*.md` file under the mirror root and:

1. Removes the exact `Documentation Index` header block at the top of the file
   (3 lines plus the following blank line).
2. Rewrites markdown link destinations `](/docs/<path>)` into relative links.
   The relative prefix depends on the file depth inside the mirror:

   | File location            | Prefix   | Resulting link            |
   | :----------------------- | :------- | :------------------------ |
   | root, e.g. `index.md`    | *(none)* | `bundler/loaders`         |
   | `runtime/...`            | `../`    | `../bundler/loaders`      |
   | `guides/binary/...`      | `../../` | `../../runtime/sqlite`    |

   URL fragments (e.g. `#conversion`) are preserved.

## What the script deliberately leaves untouched

- **Fenced code blocks** (``` and ~~~) — their content is never rewritten.
- **External URLs** such as `https://developer.mozilla.org/...` and
  `https://bun.com/...`.
- **The upstream `/docs/docs/...` typo** (e.g.
  `[Bun.Glob](/docs/docs/api/glob)`). It is an official-documentation bug;
  the script preserves it verbatim until the upstream docs fix it.
- **`index.md`** entry-point files generated by The Librarian (they already
  use local relative links).

## How to run

Run the script with Bun from the project root. The mirror root defaults to
`docs/bun - v1.3.14` and can be overridden as the first argument.

```bash
# Preview changes without modifying any file
bun run .agents/skills/fix-bun-docs/scripts/fix-bun-docs.ts --dry-run

# Apply the fixes to the default mirror (docs/bun - v1.3.14)
bun run .agents/skills/fix-bun-docs/scripts/fix-bun-docs.ts

# Apply the fixes to an explicit mirror root
bun run .agents/skills/fix-bun-docs/scripts/fix-bun-docs.ts "docs/bun - v1.3.14"
```

The script prints a summary: files scanned, headers removed, links fixed, and
files changed. Use `--dry-run` first, verify the counts, then run it for real.

## Verification

After running, verify the result:

```bash
# Expect 0
grep -rl "## Documentation Index" "docs/bun - v1.3.14" | wc -l

# Expect 0 (the only /docs/ matches left are the /docs/docs/ typos)
grep -rnE '\]\(/docs/' "docs/bun - v1.3.14" | grep -v '/docs/docs/' | wc -l
```

## Script source

The script lives at `scripts/fix-bun-docs.ts` in this skill folder. The
upstream source of truth for the documentation is `https://bun.com/docs/llms.txt`.
